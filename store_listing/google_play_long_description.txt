Maintenance Schedular helps you organize equipment records, recurring maintenance, work orders, and workforce qualifications in one practical workspace. On supported native devices, operational records are stored locally; no hosted account or synchronization service is required.

BUILD YOUR EQUIPMENT REGISTRY
- Record model and serial information, location, manufacturer, operating hours, maintenance documents, and required licenses
- Add sub-assemblies and recurring maintenance tasks at component level
- Use built-in categories and task types, or create your own

PLAN UPCOMING WORK
- Forecast date-based tasks from each machine's last-check date
- Search and filter maintenance by component category, task type, interval, or text
- See work due in the next five days
- Assign tasks to employees who match the machine's required licenses
- Mark Contractor Needed when no qualified employee is available

MANAGE PEOPLE AND OUTCOMES
- Maintain employee records with skills and licenses
- Search, filter, and sort the employee list
- Use licenses—not employee skills—to determine work-order assignment eligibility
- Save Work Complete, Partial, or Bypass outcomes
- Add notes and reschedule Partial or Bypass work
- Record timestamped changes to machine and sub-assembly operating details

REPORT, MOVE, AND ENTER DATA
- Print or share PDF machine-list, schedule, and seven-day work-order reports
- Export and replace registry data with JSON
- Import or export employee and machine CSV files
- Create CSV templates for bulk entry

PERSONALIZE THE WORKSPACE
- Choose light, dark, or system appearance
- Reorder navigation tabs for your workflow
- Keep employee search, filter, and sort choices between sessions

Important details:
- Employee skills are recorded for reference; assignment eligibility requires every license specified for the machine
- Forecasts repeat from the machine's last-check date. Calendar intervals use approximations (30 days per month, 91 per quarter, 182 per half-year, 365 per year, and 730 per biannual interval)
- Hour-based tasks are recorded but do not receive forecast calendar dates
- CSV machine files contain machine-level fields, not sub-assemblies or maintenance tasks
- JSON exports omit detail history, work-order statuses, and task assignments. Importing JSON replaces the registry and clears those excluded records
- Web builds do not support the app's database functions; browser-session data is temporary. Use a native app build for persistent records
- The optional Information form needs internet access to send a support request and app/platform diagnostics
